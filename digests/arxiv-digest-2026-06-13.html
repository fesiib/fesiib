arXiv AI+HCI Digest — 2026-06-13

Fetched arXiv `cs.AI OR cs.HC` for the current run window. New papers: 167. Starred picks: 15.

⭐ Picks

SpatialClaw: Rethinking Action Interface for Agentic Spatial Reasoning

*Seokju Cho, Ryo Hachiuma, Abhishek Badki et al. — cs.CV*

Rethinks the action interface for spatial-reasoning agents, aiming to make visual/spatial tool use more deliberate rather than just prompting a VLM harder. This is directly relevant to agent interfaces and multimodal interaction, especially if the method exposes better primitives for inspection or control.

Agents-K1: Towards Agent-native Knowledge Orchestration

*Zongsheng Cao, Bihao Zhan, Jinxin Shi et al. — cs.AI*

Proposes “agent-native knowledge orchestration,” framing how agents should collect, route, maintain, and use knowledge across workflows. Worth watching because it sits at the infrastructure layer between RAG, memory, and multi-agent coordination.

EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery

*Amy Xin, Jiening Siow, Junjie Wang et al. — cs.AI*

Argues that engineering the environment around an agent can be enough to drive autonomous scientific discovery. Strong fit for Bekzat’s agent/research-assistant interests: the contribution is less another model and more the scaffold that lets agents make progress.

AgentBeats: Agentifying Agent Assessment for Openness, Standardization, and Reproducibility

*Xiaoyuan Liu, Jianhong Tu, Yuqi Chen et al. — cs.AI*

Introduces an agentified assessment setup for making agent evaluations more open, standardized, and reproducible. This is useful if you care about agent benchmarks that go beyond static leaderboards and make evaluation workflows auditable.

Adaptive Turn-Taking for Real-time Multi-Party Voice Agents

*Soumyajit Mitra, Prabhat Pandey, Abhinav Jain et al. — eess.AS*

Targets real-time multi-party voice agents with adaptive turn-taking, a core HCI problem for conversational systems. The paper is relevant for natural interaction design because turn allocation, interruption, and latency often determine whether voice agents feel collaborative or chaotic.

Mod-Guide: An LLM-based Content Moderation Feedback System to Address Insensitive Speech toward Indigenous Ethnic and Religious Minority Communities

*Dipto Das, Achhiya Sultana, Ankit Singh Chauhan et al. — cs.HC*

Builds an LLM-based moderation feedback system for insensitive speech toward Indigenous ethnic and religious minority communities. Good HCI/CSCW pick because it centers feedback, community context, and harm-sensitive interface design rather than treating moderation as only classification.

Who Pays the Price? Stakeholder-Centric Prompt Injection Benchmarking for Real-world Web Agents

*Zihao Wang, Yiming Li, Yutong Wu et al. — cs.CR*

Benchmarks prompt-injection risk in web agents from a stakeholder-centric perspective. This is a strong agent-safety paper because it asks who gets harmed by compromised agents, not just whether an attack succeeds technically.

IterCAD: An Iterative Multimodal Agent for Visually-Grounded CAD Generation and Editing

*Tao Hu, Jiaxin Ai, Licheng Wen et al. — cs.AI*

Presents an iterative multimodal agent for visually grounded CAD generation and editing. Very relevant to creativity support and multimodal authoring: it treats design as a loop of seeing, editing, and refining rather than one-shot generation.

IVIE: A Neuro-symbolic Approach to Incremental and Validated Generation of Interactive Fiction Worlds

*Micaela Vaucher, Santiago Silveira, Santiago Góngora et al. — cs.CL*

Combines neuro-symbolic generation with interactive fiction world-building, emphasizing incremental validity while authoring. Nice creativity-support angle: it tries to keep generated worlds coherent enough for interactive narrative workflows.

Reasoning for Mobile User Experience with Multimodal LLMs: Task, Benchmark, and Approach

*Ruichao Mao, Zhou Fang, Teng Guo et al. — cs.AI*

Defines tasks, benchmarks, and approaches for multimodal LLM reasoning over mobile user experience. This is close to GUI agents and mobile interaction evaluation, with obvious links to screen understanding and user-flow diagnosis.

MemRefine: LLM-Guided Compression for Long-Term Agent Memory

*Minjae Kim, Jinheon Baek, Soyeong Jeong et al. — cs.CL*

Uses LLM-guided compression for long-term agent memory. Relevant to personal assistants and durable agents because memory usefulness depends on what gets retained, compressed, and retrieved over long sessions.

Rethinking RAG in Long Videos: What to Retrieve and How to Use It?

*Yuho Lee, Jisu Shin, Nicole Hee-Yeon Kim et al. — cs.AI*

Studies what to retrieve and how to use it for RAG over long videos. Strong multimodal pick: long-video retrieval is crucial for video understanding, editing assistants, and agents that need temporal grounding.

Teach-and-Repeat: Accurately Extracting Operational Knowledge from Mobile Screen Demonstrations to Empower GUI Agents

*Yudong Zhang, Lei Hu, Daoyang Liu et al. — cs.AI*

Extracts operational knowledge from mobile screen demonstrations to empower GUI agents. This is highly relevant to human-in-the-loop teaching of agents: demonstrations become reusable procedural knowledge rather than isolated traces.

Exploring How Agent Voice Accents Shape Human-AI Collaboration in K-12 Group Learning

*Prerna Ravi, Carúmey Stevens, Ben Hurt et al. — cs.HC*

Explores how agent voice accents shape collaboration in K–12 group learning. Excellent HCI/education fit because it studies social perception and group collaboration, not just voice-agent accuracy.

Perceive, Interact, Reason: Building Tool-Augmented Visual Agents for Spatial Reasoning

*Changye Li, Meng Lu, Yi Wu et al. — cs.CV*

Builds tool-augmented visual agents for spatial reasoning under a perceive–interact–reason framing. Useful for multimodal agent design because it makes spatial reasoning an interactive tool-use problem rather than pure visual QA.
